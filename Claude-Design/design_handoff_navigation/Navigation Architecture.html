Navigation Architecture

A unified system defining what nav chrome appears on each page, on mobile and desktop — so every screen redesign can follow consistent rules.

Page Tiers

Tier A · Hub

Full navigation always present. These are daily destinations worth one tap.

Header + Bottom tabs (mobile) · Header + Sidebar (desktop)

Tier B · Deep-dive

Sub-pages reached from a hub. Header shows a back arrow. Bottom tabs still visible.

Header (back) + Bottom tabs (mobile) · Sidebar collapsed (desktop)

Tier C · Immersive

Focus-mode pages. Nav is hidden or replaced by a single exit control.

No header · No bottom tabs · Just ✕ or ← Back

Icon rail behaviour

Collapsed (default): 56px wide, shows icons only. Same 5 tabs as mobile + ··· for all pages.
Expanded: 240px on hover or keyboard shortcut (⌘\), shows icons + labels + section headers.
Header: Slimmer since sidebar handles primary nav — just status chip, bell, user avatar.

Expand on hover / ⌘\

Rail expands to 240px showing all nav groups. Collapses back on mouse leave or second shortcut.

Focus Timer (running)

Learning activities need zero distraction. Just a back arrow (←) at top-left. No sidebar, no tabs.

Crisis Mode

The entire point is removing distractions. No nav at all. Exit button only. Calm, centered layout.
