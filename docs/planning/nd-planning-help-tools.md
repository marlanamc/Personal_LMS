# ND Planning Help Tool Ideas

Potential Planning Help tools for neurodivergent users that fit the current Day Planner direction.

## Candidate Tools

- **Brain Dump to Plan**: Capture everything on your mind, sort it into now/next/later, and turn only the first few items into blocks.
- **Tiny Steps**: Break one intimidating task into 5 to 15 minute starter actions.
- **Low Energy Mode**: Build a gentle day from low-friction tasks when energy or focus is limited.
- **Task Starter**: Create a launch sequence for one task, such as open file, gather materials, set timer, and do the first 5 minutes.
- **Priority Rescue**: Reduce overwhelm by choosing one anchor task, one support task, and one backup task.
- **Transition Planner**: Add setup, cleanup, travel, and reset time between activities.
- **Recovery Replan**: Rebuild the rest of the day after getting off track without treating the day as lost.
- **Body Double Plan**: Structure work around check-ins, co-working windows, and accountability moments.
- **Motivation Match**: Pair necessary tasks with rewards, pleasant tasks, or environmental supports.
- **Decision Lightener**: Replace open-ended planning with 2 to 3 good-enough options.
- **Energy Map**: Tag tasks by mental load, physical load, and emotional resistance, then place them in a more realistic order.
- **Appointment Buffer Builder**: Wrap appointments, interviews, and classes with prep and recovery blocks.
- **Must / Nice / If Extra**: Separate the minimum viable day from bonus tasks.
- **Momentum Builder**: Start with quick wins, then ramp into deeper work once momentum exists.
- **Shutdown Helper**: Turn loose ends into tomorrow’s starter list so the day ends cleanly.

## Best Early Candidates

These seem like the strongest near-term fits for the current planner UI:

1. **Brain Dump to Plan**
2. **Tiny Steps**
3. **Recovery Replan**
4. **Low Energy Mode**
5. **Appointment Buffer Builder**

## Notes

- Keep tool outputs lightweight and visually supportive.
- Favor tools that reduce decisions rather than add more.
- Reuse the existing Day Planner rhythm: guided inputs, soft structure, and immediate schedule feedback.
