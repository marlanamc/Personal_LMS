# Implementation Manager Toolkit Templates

Use these templates as operational defaults for implementation delivery.

## 1) BRD-Lite (Implementation Brief)

- Project name:
- Business objective:
- Success metrics (baseline -> target):
- In scope (phase):
- Out of scope:
- Constraints:
- Dependencies:
- Top risks + mitigation:
- Decision owners:
- Milestones:
- Validation plan:
- Rollback/mitigation plan:

## 2) RAID Log Template

Columns:
- ID
- Type (`Risk` | `Assumption` | `Issue` | `Dependency`)
- Description
- Probability (for risks)
- Impact
- Owner
- Due date
- Mitigation/next step
- Escalation trigger
- Status

## 3) Weekly Status Update Template

- Objective status (`Green/Yellow/Red` + why)
- Milestone confidence
- Top 3 risks/issues
- Decisions needed (owner + due date)
- Completed this week
- Next 7-day plan

## 6) Defect Triage Template

- Defect ID:

- Launch impact:
- Status:

## 7) Go-Live Runbook Template

- T-60 pre-checks
- T-30 freeze and backups
- T-0 cutover steps
- T+15 smoke checks
- T+60 checkpoint
- Rollback triggers
- Escalation contacts

For each step include:
- Owner
- Verification output
- Fallback action
