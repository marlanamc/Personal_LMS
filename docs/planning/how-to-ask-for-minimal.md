# How to Ask for Minimal Design

## The Problem
Sometimes you know you want something simpler, cleaner, more minimal—but you don't know how to explain what to cut.

## What Works

### 1. Start with "I only want what's absolutely necessary"
This tells me to ruthlessly cut anything that isn't core functionality.

**Example:**
> "I only want works on this page that are absolutely necessary"

### 2. Point out specific things you're not reading
If there's text on the page and you find yourself skipping it, say so.

**Example:**
> "I am not reading all this: [paste the text]"
> "We gotta sum it in like 5 words or less"

### 3. Call out things that feel unnecessary
Even if you can't articulate why, just say "this isn't necessary" and point to it.

**Example:**
> "This isn't necessary: Ready to start capturing. Choose a tool below..."

### 4. Use words like:
- "Simple simple"
- "Clean"
- "Bare minimum"
- "Just the essentials"
- "I know what [X] is, so we don't need [explanation/description/subheading]"

### 5. Show examples (screenshots help!)
If you can point to something visual and say "get rid of this," that's gold.

## What Minimal Usually Means

When you ask for minimal, you're usually asking to remove:
- Explanatory text (you already know what it does)
- Subheadings and labels (if the content is obvious)
- Empty state messages (if they're just filling space)
- Helper text / descriptions
- Decorative elements like badges or side panels
- Multiple ways to do the same thing

## What to Keep

The absolute essentials:
- The main action/tool/feature
- Page title (usually just a short one)
- The interactive elements you actually click/use

## Example Conversation Pattern

**You:** "I want this page simpler."

**Me:** "What should I remove?"

**You:** "I'm not reading [this big paragraph]. Just make it like 3 words. And I know what these tools are, so the descriptions can go."

**Me:** [removes paragraph, removes descriptions]

**You:** "That heading isn't necessary either."

**Me:** [removes heading]

**You:** "Perfect."

## The Golden Rule

**If you're not using it, reading it, or clicking it—you probably don't need it.**

Just point and say "this" and I'll remove it. We can always add things back later.
